# 天玑 Qbot (TianjiQbot)

QQ 机器人的**东方命理 · 术数 · 西方牌占**功能合集。
从单文件机器人重构而来的模块化开源版本，可独立运行。

> 全部结果由传统术数算法与离线规则引擎自动生成，仅供传统文化学习与娱乐参考，
> 不构成任何专业建议。

## 🚀 快速开始

```bash
pip install -r requirements.txt
```

配置环境变量（QQ 开放平台 → 机器人管理页获取）：

| 环境变量 | 说明 | 默认 |
| --- | --- | --- |
| `TIANJI_APPID` | 机器人 AppID（必填） | — |
| `TIANJI_SECRET` | 机器人 Secret（必填） | — |
| `TIANJI_SANDBOX` | 沙箱环境设为 `1` | `0` |
| `TIANJI_MARKDOWN` | Markdown 回复，`0` 关闭 | `1` |
| `TIANJI_COOLDOWN` | 群聊指令冷却秒数 | `5` |

启动：

```bash
python main.py
```

群里 @ 机器人即可使用；私聊（C2C）与频道 @ 亦受支持。

## 🔒 隐私与安全

- 代码中**不含任何密钥**：AppID / Secret 全部通过环境变量 `TIANJI_APPID`、`TIANJI_SECRET` 读取。
- `.gitignore` 已忽略所有本地数据文件（`*.db`、`*.json`、`*.jsonl`、图片等）。
- 机器人不持久化任何用户数据，不记录聊天内容。
